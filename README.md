# server — 尼尔号 Go 后端

静态表、登录/游戏 TCP、资源服、GM 后台、一键启动。

## 快速开始

```bat
cd server
build.bat
start.bat
```

- 游戏网页：http://127.0.0.1:41520/
- GM 后台：http://127.0.0.1:29180/（默认 `admin` / `admin`）
- 改对外 IP：编辑 `configs/advertise_host.txt` 后重新 `start.bat`

**完整步骤（开网页、创号、GM）见 [后端使用说明.md](./后端使用说明.md)。**  
**已完成功能清单见 [已完成内容说明.md](./已完成内容说明.md)。**
